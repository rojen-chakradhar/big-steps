# Big Steps
This is a game where we die and go to head=ven but to get to the heaven, we have to climb very big steps while being pushed back by wind, our strength running out and hell coming to get us.
###### Its very hard to get into heaven!

## inputs
D, arrow right = walk
shift, space = run
